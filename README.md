Une fois installées, les applications se mettent à jour toutes seules. Il faut un compte LT-Music.

## Installer

- **Android** : ouvrir le fichier .apk sur le téléphone et autoriser l'installation depuis cette source quand
  Android le demande.
- **Windows** : lancer le .exe. Il n'est pas signé par un certificat payant : si Windows SmartScreen s'affiche,
  choisir « Informations complémentaires », puis « Exécuter quand même ».
- **Mac** : ouvrir le .dmg et glisser LT-Music dans Applications. Elle n'est pas signée par un certificat
  payant : au premier lancement, ouvrir Réglages système → Confidentialité et sécurité, puis « Ouvrir quand même ».
- **Montre Wear OS** : installer le .apk sur la montre (par exemple par le débogage ADB en Wi-Fi).

Chaque version donne l'empreinte SHA-256 de son fichier, pour vérifier le téléchargement.
